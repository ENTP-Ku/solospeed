시간포매팅, 시간으로 정렬 등 아무튼 시간으로 뭔가를 하는 설정은 백에서 다루는게 좋다.
포매팅도 훨씬 깔끔하고 오름차순 내림차순 반영하는것도 훨씬 단순하게 할수있다. 심지어 한글도 된다.
다만 프론트로 어떻게든 포매팅 하고싶으면
const formatDate = (date) => {
  const year = date.getFullYear(); // 연도
  const month = String(date.getMonth() + 1).padStart(2, '0'); // 월 (0부터 시작하므로 +1)
  const day = String(date.getDate()).padStart(2, '0'); // 일
  const hours = String(date.getHours()).padStart(2, '0'); // 시
  const minutes = String(date.getMinutes()).padStart(2, '0'); // 분

  return `${year}년 ${month}월 ${day}일 ${hours}:${minutes}`; // 원하는 형식으로 반환
};
이거써라 이게 완벽하다

채팅관련로직은 우선은 모든 채팅레코드를 끌어다놓고 하나씩 빼는게 유리하다.
전체 채팅을 전부 들고와서 수신자 또는 발신자에 내이름이 아닌것을 전부 지우고, 수신자 또는 발시자에 상대방 이름이 아닌것을 전부 지우면 나와 상대방의 대화만 남게 된다는 식이다.
